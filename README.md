让 Codex 的话题标题跟上你正在做的事情。每轮对话结束后，自动参考最近 3～5 轮内容更新标题，话题再多，也更容易找到。

本仓库是基于 [oil-oil/oil-codex-title](https://github.com/oil-oil/oil-codex-title) 修改的 fork。**当前维护与安装来源为 [aifuxi/oil-codex-title](https://github.com/aifuxi/oil-codex-title)**，安装、更新和反馈请以本仓库为准。

## 一眼看出正在做什么

以下为命名效果示例：

| 原来的标题 | 更容易找回的标题 |
| --- | --- |
| 回应中文问候 | 🧩 邮箱验证码｜过期排查 |
| 确认注册功能 | 🧩 支付回调｜重复发货修复 |
| 讨论视频标题 | 🎬 图像模型评测｜视频策划 |
| 继续修改 | 🎨 登录表单｜布局优化 |

统一采用 **「类别 emoji + 对象｜目标」**，先找对象，再看正在做什么。

- **对象在前**：把“CRT 转场”“登录表单”等辨识词放到前面，默认省略外层已有的项目名。
- **类别固定**：🎬 内容制作、🧩 工具开发、🔎 对比调研、🎨 页面设计、📝 方法整理。同一个视频进入修改阶段，也不会因此换成开发图标。
- **名称稳定**：准确的对象名称尽量不变；旧标题整理一次，之后只在工作目标实质变化时更新；“继续”“推送”不会取代主线。
- **不打断对话**：独立模型通过后台 Stop Hook 命名，只更新标题元数据，不往原对话里添加消息。
- **跟随你的语言**：根据最近几轮用户消息的主要语言命名，保留产品名；偶尔一句外语不会让标题来回切换。例如：🧩 Email verification｜Fix expiry。
- **减少重复消耗**：稳定标题后的纯确认最多连续两轮免模型保留，重复内容与已归档话题也会跳过模型调用。
- **模型可单独配置**：命名可独立选择模型、推理与服务档位，归档继续使用自己的有效配置；设置会检查当前账号支持的能力。
- **用量与耗时可查**：按命名、归档和模型配置查看调用尝试与 Token，另有各阶段耗时统计；这些耗时不代表完整的桌面显示延迟。
- **由你控制**：可以预览新标题、固定喜欢的名称，也可以随时暂停或恢复自动命名。
- **可选闲置归档**：定期收起长期未聊、已经完成的话题，保护置顶与待办。先预览再开启；已归档话题不再参与模型评估，相同内容也不会每天重复判断。

## 让 Codex 帮你安装

需要支持生命周期 Hook 的本地 Codex 桌面版本、Python 3.10+ 和已登录的兼容 Codex CLI，无需另行配置 API Key。

复制下面这段话发给 Codex：

```text
请从 https://github.com/aifuxi/oil-codex-title 下载并安装完整的 Codex 插件（包含 Stop Hook，不要只安装 Skill），以这个 fork 为安装和更新来源。请完成本地插件市场配置、开启 Hook 并运行 doctor 检查；需要我在界面中信任 Stop Hook 时，请告诉我具体操作。最后在新话题中验证自动命名是否实际触发。
```

安装插件后还需单独信任 **Stop Hook**。完成安装与信任后，在新话题里正常聊天即可；插件不会自动批量重命名历史话题。

命名与归档默认使用 **GPT-6 Luna、low 推理、Fast 服务档位**，消耗当前 Codex 账号的模型额度，Fast 会增加用量。命名模型可单独修改；配置和恢复旧模型的方法见[详细使用说明](docs/使用与边界.md)。默认切换不代表所有质量案例通过或整体桌面延迟已经改善，评测结果见[发布验收](docs/发布验收.md)。

## 日常怎么用

直接对 Codex 说：

- “预览这个话题的新标题。”
- “固定这个话题的标题。”
- “暂停自动命名。” / “恢复自动命名。”
- “查看命名与归档的用量和耗时。”
- “预览可以归档的闲置话题。” / “每天帮我整理闲置话题。”

闲置归档默认关闭，先预览候选与保护规则，再按你的要求启用定期整理。独立评估模型的用量可查，定时管理 Agent 自身的消耗另计。

## 支持范围与验证

目前为**预览版**：

| 平台 | 当前支持范围 |
| --- | --- |
| macOS | 唯一完整支持与验收平台 |
| Linux | 保留 Python 3.13 基础程序回归，桌面完整流程未实测 |
| Windows | 不再纳入开发、CI 与发布验收，旧兼容代码和记录仅供历史参考 |
| 云端 / ChatGPT Work | 不支持此本地话题适配器 |

最新 macOS 验收已确认自然 Stop Hook 触发与标题元数据读回，尚未验证本轮桌面显示。部分桌面版本的置顶列表可能仍显示旧标题，可让 Codex“检查真实标题并同步桌面显示”。程序测试、模型评测、真实 Hook 触发和桌面显示分别记录，详见[兼容性与验证记录](docs/发布验收.md)。

开发使用 Python 标准库，`mise.toml` 固定 Python 3.13.16；`mise run check` 运行程序回归与合成案例数量检查，不调用外部模型。实际模型评测需显式使用 `--live`，具体命令见[mise 开发环境](docs/开发环境.md)。
